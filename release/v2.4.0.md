# Catalyst Data v2.4.0 — Global Statistics Connector Pack

v2.4.0 adds the first institutional statistics providers to Catalyst Data's governed external-source network.

## Included providers

- World Bank v2 country catalog.
- World Bank v2 indicator catalog.
- World Bank country/indicator observations with pagination, date ranges, and footnotes.
- UNSD SDG goals.
- UNSD M49 geography catalog.
- UNSD SDG indicator/series metadata.
- UNSD paginated indicator observations with dimensions.

## Governance

Provider acquisition is backend-only. Every fetch records request context, response SHA-256, source URI, result count, and retrieval time. Repeated observations update the current cached record without duplicating identity, while fetch history remains immutable.

## WordPress

The Sustainable Catalyst Data plugin adds cached global-statistics status and `[catalyst_data_statistics]`. WordPress never stores provider/database credentials and cannot initiate upstream acquisition.
