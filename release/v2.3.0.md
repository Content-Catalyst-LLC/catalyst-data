# Catalyst Data v2.3.0 — Internet Archive & Wayback Intelligence

v2.3.0 is the first provider-specific implementation on the v2.2 external-source adapter framework. It adds governed Archive.org catalog search, item metadata and file inventories, plus Wayback availability and CDX capture history.

## Boundaries

- Archive resources are catalog/evidence objects, not forced into the measurement contract.
- Automated requests identify Catalyst Data with a descriptive User-Agent.
- 429 and Retry-After behavior is respected with bounded retry/backoff.
- Public WordPress/API discovery reads Catalyst Data's cached catalog; unauthenticated WordPress traffic does not become an Archive.org crawler.
- Metadata/item version history is preserved with immutable snapshots.
- Files are cataloged by default; v2.3.0 does not mass-download Archive.org holdings.
