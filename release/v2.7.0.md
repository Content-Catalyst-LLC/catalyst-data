# Catalyst Data v2.7.0 — Space & Scientific Data Network

Released: August 11, 2026

## Purpose

Extend Catalyst Data's governed external-source network into space weather, solar-system objects, close approaches, and exoplanet science without making WordPress, Site Intelligence, or other consumers own provider-specific acquisition.

## Providers

- NASA DONKI for cached space-weather event records.
- NASA/JPL Small-Body Database Query API for source-native small-body identifiers and orbital/physical catalog fields.
- NASA/JPL Close-Approach Data API for bounded close-approach observations.
- NASA Exoplanet Archive TAP for bounded, table-driven exoplanet discovery.

## Boundaries

- WordPress reads cached Catalyst Data only and cannot initiate upstream provider acquisition.
- NASA API keys remain backend environment secrets and are redacted from persisted request URIs.
- JPL and Exoplanet Archive records preserve source-native identifiers and raw provider payloads.
- Queries are bounded; response-size and retry protections from the shared provider client remain active.
- Close-approach and space-weather records are evidence/data products, not hazard predictions or safety advice.
