# Catalyst Data v2.6.0 — Earth, Climate & Ocean Data Network

Released: August 11, 2026

## Purpose

Extend Catalyst Data's governed external-source network into environmental observations and hazards without making Site Intelligence or WordPress own provider-specific ingestion.

## Providers

- NOAA NCEI Climate Data Online v2 for climate/station observations.
- NOAA/compatible ERDDAP catalogs and bounded TableDAP observations.
- U.S. IOOS Data Catalog discovery, preserving catalog resources and metadata.
- USGS FDSN earthquake GeoJSON events with source-native event IDs and coordinates.

## Boundaries

- WordPress reads cached Catalyst Data only and cannot initiate provider acquisition.
- NCEI tokens remain backend environment secrets and are never persisted.
- Provider responses are bounded by the existing 20 MB safety ceiling and retry policy.
- Geographic coordinates are stored as normalized numeric fields plus source geometry JSON; PostGIS remains an additive future optimization.
