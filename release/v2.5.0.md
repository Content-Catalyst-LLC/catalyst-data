# Catalyst Data v2.5.0 — U.S. Public Data Connector Pack

v2.5.0 extends the governed external-source network with six U.S. federal data providers: Census, BLS, BEA, EIA, EPA Envirofacts, and USGS Water Data.

## Added
- U.S. Census Data API adapter and cached observations.
- BLS Public Data API v2 single-series adapter, catalog metadata, footnotes, and observations.
- BEA Data Retrieval API adapter with environment-only UserID injection.
- EIA Open Data API v2 adapter with facets and bounded offset pagination.
- EPA Envirofacts Data Service adapter with filters and bounded range pagination.
- USGS Water Data OGC API adapter with geospatial observation payloads.
- Migration 018 with provider-specific tables, normalized `us_public_observations`, immutable fetch provenance, and status view.
- Cached public API surfaces under `/v1/us-public/*`.
- `[catalyst_data_us_public]` WordPress shortcode and federal-data admin diagnostics.

## Trust boundary
Provider credentials are read from backend environment variables and are redacted from stored source URIs. WordPress consumes only cached Catalyst Data API projections and cannot initiate provider acquisition.
