# Catalyst Data v2.8.0 — Dataset Catalog, Registry & Discovery

Released: 2026-08-11

## Purpose

Unify the provider-specific caches built through v2.7 into one rebuildable, searchable dataset registry while preserving provider-native records as the source of truth.

## Added

- migration 021 dataset catalog schema
- stable cross-provider catalog identifiers
- provider-native dataset keys
- resource-kind, publisher, coverage, freshness, record-count, tag, and metadata indexing
- append-only catalog synchronization history
- `catalog-sync`, `catalog-search`, `catalog-get`, and `catalog-status` CLI operations
- cached public catalog API endpoints
- WordPress `[catalyst_data_catalog]` discovery surface
- catalog status in WordPress administration

## Boundaries

Catalog synchronization uses only already-governed Catalyst Data caches. It does not call upstream providers, does not alter provider-native records, and does not expose provider credentials through WordPress or public API requests.
