# Catalyst Data v3.0.0 — Connected Data Graph & Cross-Source Federation

v3.0.0 promotes Catalyst Data from a set of governed provider caches and canonical identifiers into a connected, queryable data substrate.

## Added

- Migration 023 for relational graph nodes, typed/source-backed edges, immutable edge events, immutable sync runs, and graph status.
- `ConnectedGraphService` with deterministic synchronization, search, neighbor queries, bounded shortest paths, entity federation, and JSON-LD-compatible export.
- Dataset-to-provider, entity-to-provider, entity-to-statistical-series, JPL close-approach/small-body, and NASA exoplanet/stellar-host relationships.
- Cross-source cached federation through canonical World Bank, UN SDG, and Census identifiers.
- Public read-only `/v1/graph/*` API endpoints.
- CLI graph and federation commands.
- WordPress graph status, REST proxy, and `[catalyst_data_graph]` shortcode.

## Boundaries

- Provider-native caches remain authoritative.
- Graph synchronization never initiates upstream acquisition.
- Ambiguous identity relationships remain unresolved rather than inferred by fuzzy matching.
- Public API and WordPress paths cannot mutate graph history.
- JSON-LD export is a bounded interoperability representation, not a replacement for source-native data.
